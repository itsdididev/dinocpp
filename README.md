# Dino Offline (C++ + raylib)

Controles: **Espacio / ↑** saltar, **↓** agacharse, **Espacio** reiniciar.

Compilar (requiere CMake y un compilador C++, p. ej. MinGW o Visual Studio):

    cmake -S . -B build
    cmake --build build --config Release
    build\Release\dino.exe   (o build\dino.exe con MinGW)
